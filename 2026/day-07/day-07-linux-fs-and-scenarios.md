      ├── bin
      ├── usr
      │    └── bin
      └── opt

The top-most directory in Linux.
All files and directories start from here.


## I would use this when...

I need to navigate the Linux file system or locate important system directories.

## 2. /home
Purpose
Stores home directories of regular users.
Each user gets a separate folder.
Example (ls -l /home)
I would use this when...
I want to access my personal files or another user's home directory.

## 3. /root
Purpose
Home directory of the root (administrator) user.
Only the root user has access.
Example (ls -l /root)
.bashrc
.bash_history
I would use this when...

I am logged in as root and need to manage system-level files.
## 4. /etc
Purpose
Stores system configuration files.
Most Linux services keep their configuration here.
Example (ls -l /etc)
hostname
hosts
passwd
ssh/
I would use this when...

I need to configure services like SSH, Nginx, or change system settings.

## 5. /var/log
Purpose
Stores log files generated by the operating system and applications.
One of the most important directories for troubleshooting.
Example (ls -l /var/log)
syslog
auth.log
nginx/
I would use this when...

I need to troubleshoot application or server issues by checking logs.
## 6. /tmp
Purpose
Stores temporary files.
Files may be removed automatically after reboot.
Example (ls -l /tmp)
systemd-private/
tmpfile.txt
I would use this when...

I need temporary storage for scripts or application files.
## 7. /bin
Purpose
Stores essential Linux commands needed during boot and system recovery.
Example (ls -l /bin)
ls
cp
mv
I would use this when...

I need basic Linux commands like ls, cp, or mv.
## 8. /usr/bin
Purpose
Stores most user-level executable programs.
Contains hundreds of commonly used commands.
Example (ls -l /usr/bin)
python3
git
vim
I would use this when...

I run installed programs such as Git, Python, or Vim.
## 8. /usr/bin
Purpose
Stores most user-level executable programs.
Contains hundreds of commonly used commands.
Example (ls -l /usr/bin)
python3
git
vim
I would use this when...

I run installed programs such as Git, Python, or Vim.
## 9. /opt
Purpose
Stores optional or third-party applications.
Software installed manually is often placed here.
Example (ls -l /opt)
google/
tomcat/
I would use this when...

I install third-party software that is not part of the default Linux installation.
# Hands-on Practice
1. Find the Largest Log Files
 // du -sh /var/log/* 2>/dev/null | sort -h | tail -5 //
What it does
du -sh → Shows size of each file/folder
2>/dev/null → Hides permission errors
sort -h → Sorts by human-readable size
tail -5 → Displays the five largest entries
📝 Memory Trick
/        → Everything starts here
/home    → User files
/root    → Root user's files
/etc     → Configuration files
/var/log → Logs for troubleshooting
/tmp     → Temporary files

/usr/bin → Installed user programs
/opt     → Third-party applications
